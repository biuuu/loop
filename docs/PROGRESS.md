更新于 2026-11-18。现已支持大厅、每人一个持久房间、房主管理、1–6 个可配置舞台位置，以及四种可切换预设环境。房间使用全屏跟随镜头、浮动播放器和弹出面板，角色为可选毛色/花纹的像素猫。当前提供昵称临时入口，邮箱 UI 隐藏。用户已在海外部署验证站点扫码登录后能解析歌曲，匿名结果与本地不同。下方按时间保留历史决策和验证记录，以最新记录为准。

## 已完成

- 单项目 Vue 3 / PixiJS 前端、Fastify / Socket.IO 后端，生产构建由一个 Node 服务提供。
- SQLite 直接 SQL、按版本执行的迁移、持久化游客身份与独立个人歌单。歌单增删排序保留下一首的轮播位置。

- 网易云搜索、歌曲资料和播放地址解析已集成最小协议代码并记录 MIT 归属；不需要运行旧 API 项目。

## 接手入口

1. 先读 `docs/PLAN.md`，区分用户决定和可调整默认值。
2. 按 `README.md` 启动：`npm run dev`，打开 `http://localhost:5173`；用普通与无痕窗口体验两个独立身份。
3. 常规检查：`npm run check`、`npm test`、`npm run build`。可选 `npm test -- --browser --live` 做浏览器与真实上游验证；需要 Chromium，已有浏览器可传 `--chromium=/绝对路径/chrome`。
4. 本地 Node 24.13.0 / npm 11.6.2。若 `.git` 为只读占位且本地已有 `.loop-git/`，按上文「Git 提交与推送约定」操作。
